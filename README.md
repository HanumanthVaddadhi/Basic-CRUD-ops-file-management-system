File Management System

The File Management System is a simple project developed to perform basic file operations using Python. It allows users to create, read, update, and delete files efficiently. The project uses Python's built-in `pathlib` and `os` modules to interact with the file system.

The project consists of four main functions: file creation, file reading, file updating, and file deletion. The file creation function checks whether a file already exists and creates a new file if it does not. The file reading function reads and displays the contents of an existing file. The file updating function allows users to modify the contents of a file by writing new content, replacing the existing content. The file deletion function removes a specified file if it exists.

Exception handling is implemented using `try-except` blocks to handle errors that may occur during file operations. The program also checks for file existence before performing reading, updating, or deleting operations, helping prevent common errors.

This project demonstrates fundamental Python programming concepts, including functions, conditional statements, user input, exception handling, file handling, and the use of built-in modules. It is useful for beginners who want to understand how Python interacts with files and manages basic file operations.

Future improvements may include adding a menu-driven interface, supporting content appending, implementing file renaming and copying, and introducing additional file validation and security features.
